## C. 置き場所と費用（2026-11-22）

置き場所は GCP のままにした（[決めたことの記録](./decisions.md) 2026-11-22・[置き場所の比べと料金の試算](./hosting-cost.md)）。そのうえで、あとでやることと、まだ決めていないこと。

| # | やること | いつ | メモ |
|---|---|---|---|
| C1 | 独自ドメインを取り、Cloudflare の無料プランを前に置く | 一般に公開するとき | `.com` で年 約10.5ドル。Terraform に Cloudflare のプロバイダーを足す。利用者の IP を `CF-Connecting-IP` から読む（今は `TRUSTED_PROXY_HOPS=1`）。`WEB_URL`・LIFF のエンドポイント・LINE ログインと Threads の OAuth の戻り先を替える。Cloudflare と Cloud Run のつなぎ方（ドメインの割り当てか、転送先の名前の書き換え）は要確認 |
| C2 | Cloudflare のキャッシュの下準備 | C1 の前でもよい | 誰が見ても同じ公開の API に `Cache-Control: s-maxage` を付ける。画面の側で同じデータを取り直さない設定（TanStack Query）を見直す |
| C4 | 定期の仕事を軽くする | 1日の利用者が600人を超えたら | まず、やることがない回を1回の問い合わせで切り上げ、片付けを1日1回にする（CPU の時間が減る。間隔は変えない）。それでも気になれば呼ぶ回数を減らす（その頃は利用者の要求が台を温めるので、起動の待ちは増えない） |
