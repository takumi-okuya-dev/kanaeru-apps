## User Scenarios & Testing *(mandatory)*

### User Story 1 - 運用アカウントを作り、戦略を書く (Priority: P1)

ログインした人が `/threads` で運用アカウントを名前だけで作ると、戦略の画面へ移る。区分ごとの欄（どれも空でよい）と口調のチップに入れて保存する。

**Independent Test**: アカウントを作り、戦略を保存して読み直すと残っていること。ほかの人のアカウントは 404 になること。

**Acceptance Scenarios**:

1. **Given** アカウントがない, **When** 名前を空で「作る」, **Then** 欄のそばに「アカウントの名前を入れてください。」
2. **Given** 名前を入れた, **When** 「作る」, **Then** 戦略の画面へ移り、上の帯に「アカウントを作りました。まず戦略を書いてください。」
3. **Given** 10個持っている, **When** 作る, **Then** 409（画面では「これ以上作れません」）
4. **Given** ほかの画面で先に戦略を保存した, **When** 古い版で保存, **Then** 409 と「ほかの画面で先に保存されました」

---

### User Story 2 - プロンプトを作り、AI の答えを貼って案をためる (Priority: P1)

「案を作る」で件数と文字数を決め、「プロンプトを作る」でコピーして外の AI に貼る。返ってきた答えを貼ると、何件に分かれるかが出て、「案をためる」で投稿の案の画面へ移る。

**Independent Test**: `@@@` の行で3件に分かれること・同じ送り直しで二重にならないこと・戦略と NG ワードと却下の理由がプロンプトに入ること。

**Acceptance Scenarios**:

1. **Given** 3件を `@@@` で区切った答え, **When** 貼る, **Then** 「3件の案に分かれます。」。ためると3件が承認待ちになる
2. **Given** 区切りのない答え, **When** ためる, **Then** 全体を1件にする
3. **Given** 1件が2,000文字を超える, **When** ためる, **Then** 欄のそばに何件目かを出す
4. **Given** NG ワードと却下した案がある, **When** プロンプトを作る, **Then** それらがプロンプトに入り、要約に数が出る

---

### User Story 3 - 案を承認・却下する (Priority: P1)

投稿の案の画面で、状態（承認待ち・承認済み・却下）をチップで選ぶ。案ごとに文字数・NG ワード・規約に注意・似ている度合いが出る。1件ずつか、選んでまとめて承認・却下する。却下は理由（いくつでも）かメモが要る。

**Independent Test**: 承認・却下・承認待ちに戻すが状態どおりに動くこと。NG ワードを含む案と500文字を超える案は承認できないこと。

**Acceptance Scenarios**:

1. **Given** NG ワードを含む案, **When** 見る, **Then** 「NGワード：…」の札が出て、「承認する」は押せない（API も 409）
2. **Given** 承認待ちの案, **When** 「却下する」で理由を選ばずに送る, **Then** 枠の中に「却下の理由を選ぶか、メモを書いてください。」
3. **Given** 2件を選んだ, **When** 「選んだ2件を承認」, **Then** 2件が承認済みになる。1件でも版や状態が合わなければ、どれも変えない
4. **Given** 却下した案, **When** 却下のチップを選ぶ, **Then** 「却下の理由：…」が出て、「承認待ちに戻す」で戻せる

## Requirements *(mandatory)*

- **FR-1**: 運用アカウントは持ち主の kanaeru のアカウントのもので、ほかの人には 404。
- **FR-2**: 機能の印 `threads.app` が切なら、窓口はどれも 404。
- **FR-3**: 戦略は版で保存の衝突を止める。
- **FR-4**: プロンプトはめぐるの `buildPrompt` で作り、アプリは外の AI に何も送らない。
- **FR-5**: 案は `@@@` の行で分け、同じ `clientRequestId` は二重にためない。
- **FR-6**: 承認は NG ワードと Threads の上限（500文字・リンク5つ）で止める。まとめての操作は全部か何もしないか。
- **FR-7**: 画面は kanaeru の部品（`@workspace/ui`）と `tokens.css` の値だけで作り、EXPERIENCE.md の振る舞い（誤りは欄のそば・結果はボタンの近く・移るときは上の帯・消す前は確かめ・夜間の停止）に従う。
