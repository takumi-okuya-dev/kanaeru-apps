## User Scenarios & Testing *(mandatory)*

### User Story 1 - 承認するときに時間差のメンションを付ける (Priority: P1)

設定でメンションする人を足し、投稿の案のカードの「メンションを付ける」を押すと、「いつも付ける」の人が選ばれた状態で返信の文が出る。人のボタンで入れ替え、文を直して保存し、案と一緒に承認する。投稿のあと時間差がたつと、その投稿への返信で文が出る。

**Acceptance Scenarios**:

1. **Given** 時間差30分・承認した案にメンション, **When** 投稿から20分の回, **Then** 出さない。31分の回で返信が出て、カードに「メンション済み」と返信の URL
2. **Given** ほかの案の予定に入っている人, **When** 付ける, **Then** 409（選べない理由がボタンに出る）
3. **Given** 返信の文に NG ワード, **When** 承認, **Then** 承認できない
4. **Given** 承認済みの案に付け直す, **When** 保存, **Then** 承認待ちに戻る
5. **Given** 却下, **Then** まだ出していないメンションも消える

### User Story 2 - 人・ひとこと・時間差を決める (Priority: P1)

**Acceptance Scenarios**:

1. **Given** 形の違うユーザー名・自分・同じ人, **When** 足す, **Then** 欄のそばに誤り
2. **Given** 予定に入っている人を消す, **When** 確かめて消す, **Then** 承認待ち・承認済みの案は文からその人を外して承認待ちに戻る。投稿済みの予定は出さない
3. **Given** NG ワードを含むひとこと, **Then** 保存できない

### User Story 3 - 投稿済みの投稿にあとからメンションする (Priority: P2)

投稿から7日以内で、まだ付けていない投稿のカードで「メンションを付ける」→「返信する」を押すと、次の回に返信が出る。

### User Story 4 - 出せなかったときにわかる (Priority: P2)

投稿が見つからない・投稿されなかった・返信の権限がない・時間が過ぎた・NG ワード・同じ人が多すぎる・Threads が受け付けない、をカードに出す。

## Requirements *(mandatory)*

- **FR-1**: 承認した返信の文は書き換えずに出す。出す直前に NG ワードと「同じ人は24時間に1回」を確かめ、当たれば出さない。
- **FR-2**: 二重に出さない（借り・公開を送った日時・コンテナーの状態の照らし合わせ）。
- **FR-3**: 認証のエラーは「接続し直しが要る」にして待つ（24時間を過ぎたら出さない）。
- **FR-4**: 持ち主だけが読める・書ける（ほかの人は 404）。設定・人・付ける・外すは操作の記録に残す。
