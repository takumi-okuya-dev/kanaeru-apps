# Quickstart：チェックイン（reception-001）を確かめる

## 1. 手元（自動）

```bash
pnpm install
pnpm local:setup     # checkin の表ができる
pnpm check
```

## 2. 手元（手で）

`.env` の `ORGANIZER_LINE_USER_ID` に手元のログインで使う LINE のユーザー ID を入れて `pnpm dev`。

1. 主催者でログインし、交流会を作る（event-001 の quickstart）。準備の画面の受付QRの下の URL（`/e/{id}/checkin`）を写す。
2. 別のブラウザで別の ID でログインし、その URL を開く。名前に表示名が入っている。チップを選んで「チェックインする」→「チェックインしました」。開き直すと「チェックイン済み」。
3. 主催者の一覧画面（`/admin/events/{id}`）に、5秒以内にその人が出る。「手でチェックイン」で同じ名前を入れると、両方に「同じ名前があります」。
4. 行を押して支払い方法を直し「保存」→ 合計のタブの数字が変わる。手の行を「取り消す」。
5. 書き出しと削除（`/admin/events/{id}/data`）で「参加者をCSVで書き出す」→ Excel で開いても文字化けしない。
6. 準備の画面でアンケートを開き、参加者の画面を開き直すと「アンケートに答える」が出る。

## 3. 本番に出したあと（手で）

- [ ] 受付QRを LINE のカメラで読み、ミニアプリでチェックインまで1分以内に済む
- [ ] 2台の端末（受付係）で、一覧と合計が5秒以内にそろう
- [ ] 書き出した CSV を Excel で開いても文字化けしない
- [ ] Cloud Logging に参加者の名前が出ていない
