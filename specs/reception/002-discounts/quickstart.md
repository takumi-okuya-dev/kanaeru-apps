# Quickstart：割引・紹介割（reception-002）を確かめる

## 1. 手元（自動）

```bash
pnpm db:migrate   # event_discount の表と、checkin の4つの列ができる
pnpm check
```

## 2. 手元（手で）

1. 主催者で交流会を直す（A2）。参加費 5,000、「割引を足す」→ 紹介割・1000・「紹介者の名前を聞く」→ 保存。
2. 別の ID で P1（`/e/{id}/checkin`）を開く。支払い方法のあとに「割引なし」「紹介割（−1,000円）」。紹介割を選ぶと「紹介してくれた人の名前」が出る。入れてチェックイン。
3. A3 の合計のタブ：PayPay 1人・4,000円。主催者の内訳に「紹介割 1人・1,000円」と紹介者の名前。
4. 受付係で同じ行の直す枠を開く：紹介者の欄は空。空のまま保存しても、主催者の枠には名前が残る。
5. A5 の CSV に「割引」「割引の額」「紹介者」の列。

## 3. 本番に出したあと（手で）

- [ ] 紹介割を選んだチェックインの金額が、参加費 − 割引になっている
- [ ] Cloud Logging に紹介者の名前が出ていない
