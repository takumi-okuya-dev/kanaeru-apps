# Quickstart: 交流会の持ち主と組織（event-002）

2026-11-20 作成。手元（`pnpm dev`・試験用のログイン）で確かめる手順。

1. 手元のログイン（`/dev/login`）で、運営者でない人 A としてログインし、交流会の一覧の「交流会を追加」から交流会を作る。一覧の行に「持ち主：A」「個人」が出る。
2. 別の人 B（運営者を含む）でログインし、一覧に A の交流会が出ないこと、A の交流会の URL を開くと「この交流会の管理の画面は使えません」になることを確かめる。
3. A で組織を作り（設定 › 組織）、B を招待のリンクで入れて編集者にする。A の交流会の準備の画面の「持ち主と組織」で組織を選んで保存する。
4. B で一覧を開くと交流会が出て、直す・準備が使える。B の準備の画面では、組織の選択が出ず「組織に入れる・外すのは、持ち主だけです。」と出る。
5. A が B をメンバーに下げると、B は一覧に出ず、開くと使えない（部員）。
6. A が「入れない（個人）」で外すと、B は使えない。
7. A を組織に入れたまま、A で設定 › アカウントの退会の確かめを開くと、「交流会「…」は、…さん（組織「…」の管理者）に引き継がれます。」が出る（A が管理者なら、引き継ぐ人が先に要る）。
8. 運営者の確かめ：DB で `UPDATE event SET owner_account_id = NULL` とし、運営者（`.env` の `ORGANIZER_LINE_USER_ID`）で一覧を開くと、すべての交流会が運営者のものとして出る。
