# Quickstart: 人物メモの最初の版（person-001）

## 前提

- 先に入れる共通の PR（予期しないエラーのログ・OAuth の範囲・import の許す一覧。[research.md](./research.md) R2）が `develop` に入っている。
- 作業場所の `.env` と手元の DB（[並行開発の決まり](../../../docs/rules/parallel-development.md) 1章）。`pnpm local:setup`、そのあと `pnpm dev`。
- 運営者（`ORGANIZER_LINE_USER_ID` の人）でログインする。台帳に行がない間は、運営者にだけ見える。

## 自動の確かめ

```bash
pnpm db:check                     # pr1：DB の変更の作り忘れ・順番
pnpm --filter api test -- person  # 表・窓口・ログに出ないこと
pnpm --filter @workspace/contracts test -- person   # そろえ方・当たった位置・URL の組み立て
pnpm --filter web test -- person  # 画面
pnpm check                        # PR の前に全部
```

## 手での確かめ（pr2・ステージング）

1. `/person` を開き、「このメモを見られるのはあなただけです」が出ることを確かめる。
2. 人を足す。
   1. フルネームだけで足せる。
   2. 「田中 太郎」に、よみ「たなか」・LINE の名前・見た目の特徴・話したこと・次に話したいこと・タグ「AI」を書く。
   3. 開き直すと、話したことと次に話したいことが最初に出る。
3. 探す。
   - 「タナカ」「ｇｏ」「たろう」で当たり、当たった所が前後の文と一緒に出る。
   - 画面の URL に、検索の言葉が出ない。
   - 画面を読み直すと、検索は空に戻る。
4. 会った場を作る。
   1. 「11月の AI 勉強会」と日付で作る。
   2. 同じ名前と日付で作り直すと、前のものが選ばれる。
   3. その画面で続けて3人を足す（新しい2人と、前の1人を付ける）。
   4. 会った場に3人が並ぶ。
5. 書き足す。
   1. 会った場を選んで書き足すと、見出しに日付と会った場が入る。
   2. 機内モードで保存すると「保存できませんでした」と出て、書いた内容が残る。
   3. 戻して保存すると、1回分だけ足される。
6. アカウントを開く。
   1. X と LINE ID を入れて押すと、相手のページと LINE のプロフィールが開く（実機の iPhone と Android で。[research.md](./research.md) R5）。
   2. そのほかの URL に `javascript:alert(1)` を入れると、保存されない。
7. 書き出す。
   - CSV が落ちる。
   - 表計算ソフトで開くと、「=1+1」で始まる話したことが文字のまま出る。
8. ログを見る。ステージングの Cloud Logging で、手で入れた言葉（例：たなか）が出ないことを確かめる。
9. 退会の確かめの画面に「人物メモ（会った人・会った場）」が出る（退会は押さない）。
