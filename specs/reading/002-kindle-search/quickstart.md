# Quickstart: 読書記録の Kindle の取りこみ・探す・あとで調べる（reading-002）

## 前の準備

- reading-001 の pr1・pr2 が `develop` に入っている。
- 持ち主が日本語の Kindle アプリで書き出した HTML を1つ受け取り、形を写した架空の見本を `apps/web/src/features/reading/import/__fixtures__/` に足してある（実物はリポジトリに置かない）。

## 自動の確かめ

```bash
pnpm check
```

1. Kindle の読み方（`kindle.test.ts`）：英語と日本語の見本で、章・ページ・位置・ハイライト・メモ（直前のハイライトに付く）が同じに取れる。「Highlight(」の空白の揺れ・「章名 >」・ページのない本・メモだけ・「…」で終わるもの。
2. Web のノートブックの貼り付け：色｜位置の行で区切れる。
3. 探す（`routes.test.ts`）：かな・全角・大文字の違いで当たる・記号は文字として・本ごとにまとまる・ほかの人の記録に当たらない・URL に言葉が出ない（POST）。
4. あとで調べる：調べていないものが先・分かったことを残すと調べた時刻が入り、消すと両方消える・取りこみ直しで消えない。
5. 調べる文（`research-prompt.test.ts`）：書名・章・文・コメント・分かりたいことが入る・3つの先の URL・2,000字をこえたらコピー。
6. ログ：探す言葉・分かったことがログに出ない。

## 手で確かめること

1. 持ち主の iPhone で、Kindle のアプリから書き出したメールの HTML を「ファイルに保存」し、取りこむ（SC-001・SC-002）。
2. 「あとで調べる」から ChatGPT・Claude・Google を開き、文が入るかを見る。
