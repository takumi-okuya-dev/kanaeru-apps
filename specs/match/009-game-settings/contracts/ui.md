# Contracts: 画面（match-009）

| 画面 | 変わること |
|---|---|
| 名簿と設定 | 「1試合（分）」「試合の始まり」「試合の終わり」を外す。「試合の数」（数・1〜60）・「試合の形」・「分け方」（チェック「レベル別」＋4つ・3つ・2つ／チェック「分けない」／チェック「ミニゲーム」＋「コート数」1〜20）。どれも外すと誤り。一覧に分け方ごとの組の人数と試合の数、ミニゲームはチームの数と1チームの人数 |
| 試合表 | 分け方が2つ以上なら「分け方」のタブ（レベル別・分けない・ミニゲーム）。レベル別の中は組のタブ。ミニゲームはコートごとのチーム（レベルの印・来る人でない人の印・チームに入っていない人）と「チーム分けをやり直す」（担当の端末）。題の下の文から「1試合◯分」を外す。「レベルの分け方」は「分け方と試合の形」 |
| 見るだけのページ | 分け方のタブとミニゲームの表（呼び名だけ）。つながらない間の見込みの文を外す |
| 大きく映す | 分け方のタブ。ミニゲームはコートごとのチームを大きな字で |
| 印刷 | 刷るものにミニゲーム（コートとチームの一覧を紙1枚）。版の題の下の文から「1試合◯分・試合 ◯〜◯」を外し、「試合 N試合」にする |
