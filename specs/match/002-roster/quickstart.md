# Quickstart: 名簿・組み方・試合表・印刷（match-002）

2026-11-22 作成。手元（`pnpm dev`・試験用のログイン）で確かめる手順。名前はどれも架空のもの。

1. 運営者（`ORGANIZER_LINE_USER_ID`）で手元のログインをし、設定 › アプリの台帳で試合表を「公開」にする（ほかの人で試すとき）。
2. `/match` を開き、「試合表を作る」で名前を入れて作る。名簿と設定の画面に移る。
3. スプレッドシートに次の表を作ってコピーし、「フォームから貼り付ける」に貼って「名簿に入れる」。メールの列は読まれず、呼び名は「高橋」「佐藤美」「佐藤健」「林優斗（印つき）」になる。

   ```text
   タイムスタンプ	メールアドレス	氏名	バドミントンのレベル
   2026/11/01 10:00:00	a@example.com	高橋 拓真	1上級
   2026/11/01 10:01:00	b@example.com	佐藤 美咲	1上級
   2026/11/01 10:02:00	c@example.com	佐藤 健司	1上級
   2026/11/01 10:03:00	d@example.com	林優斗	1上級
   ```

4. 1人を「来ない」にすると、上級が3人になり「4人に足りないので組めません」が出る。「来る」に戻し、「試合表を作る」。
5. 試合表の画面で第1試合にチェックを付けると、第2試合が墨の地になる。読み直しても残る。
6. 「印刷」で紙を A4 横にし、ブラウザの印刷の見本で、版が1枚に収まることを見る。
7. 別のブラウザ（別の端末の ID）で同じ試合表を開くと「この端末は見るだけです」が出る。「この端末で直す」を押すと、前のブラウザで直したときに「この端末は担当の端末でないため、保存できませんでした」が出る。
