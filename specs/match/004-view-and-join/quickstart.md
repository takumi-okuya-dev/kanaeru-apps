# Quickstart: 見るだけのページ・入口の QR・QR で受け付ける（match-004）

2026-11-22 作成。手元（`pnpm dev`・試験用のログイン）で確かめる手順。名前はどれも架空のもの。match-002 の [quickstart.md](../002-roster/quickstart.md) で試合表を作ってから始める。

1. 試合表の中のナビの「見るだけのページ」で「見るだけのリンクを作る」。QR とリンク、「…の終わりまで見られます」が出る。
2. 「印刷」を開くと、版の右上に QR が入る。「入口に貼る1枚も刷る」で A4 縦の1枚が足される。
3. プライベートウィンドウ（ログインなし）でリンクを開く。呼び名だけの表が出る。開発者ツールで答えの見出しに `cache-control: no-store` と `x-robots-tag: noindex, nofollow`、ページに `<meta name="robots" content="noindex, nofollow">` があることを見る。自分の名前を選ぶと印が付き、読み直しても残る。ネットを切ると「…に読んだ表を出しています」。
4. 運営の画面で「見るだけのリンク」を作り直すと、前のリンクは「見られません」。
5. 「QR で受け付ける」で「受付を始める」。プライベートウィンドウで受付のリンクを開き、名前とレベルを入れて「受付する」→「受付できました」。運営の一覧に出て、名簿と設定に入っている。同じ名前でもう1度受け付けると「同じ名前」の印。
6. 「受付を締める」と、受付のリンクは「受付は締め切られました」。
