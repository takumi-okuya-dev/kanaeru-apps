# Quickstart：アンケート（survey-001）を確かめる

## 1. 手元（自動）

```bash
pnpm install
pnpm local:setup     # survey_answer の表ができる
pnpm check
```

## 2. 手元（手で）

`.env` の `ORGANIZER_LINE_USER_ID` に手元のログインで使う LINE のユーザー ID を入れて `pnpm dev`。

1. 主催者でログインし、交流会を作る（GoogleフォームのURL・LINEグループの招待リンクも入れる）。準備の画面でアンケートを開く。
2. 別のブラウザで別の ID でログインし、チェックインの画面でチェックインしてから「アンケートに答える」。目的の案内と設問が出て、仕事の立場と職種は「答えない」が選ばれている。
3. 困りごとを書き、月いくら・テスターを選んで「送る」→ お礼と「続けて交流会のアンケートへ」「交流会のLINEグループに参加する」。開き直すと前の答えが入っていて「送り直す」。
4. 主催者の「困りごと」に、チェックインの名前で出る。「テスターに『はい』だけ」「月いくらの高い順」を試す。
5. 主催者の一覧画面で「手でチェックイン」した人の行を開き、「アンケートの回答を入れる」で入れる。アンケートを閉じても入れられる。参加者の画面は「アンケートは閉じています」。
6. 書き出しと削除で「困りごとをCSVで書き出す」→ Excel で開いても文字化けしない。
7. 受付係で開くと、管理の画面の上に「困りごと」が出ず、`/admin/events/{id}/concerns` は「この画面は主催者だけが使えます」。

## 3. 本番に出したあと（手で）

- [ ] アンケートQRを LINE のカメラで読み、ミニアプリで答えてお礼まで進める

- [ ] 書き出した困りごとの CSV を Excel で開いても文字化けしない
- [ ] Cloud Logging に困りごとの本文が出ていない
