# Kindle の書き出しの見本（架空）

`kindle-en.html`・`kindle-ja.html` は、Kindle のアプリの「ノートブックの書き出し」の HTML の形（公開されているパーサーの見本から読んだクラスの名前と並び。PRD の補足 7章）を写した、架空の文だけの見本。

- `kindle-ja.html` の言葉（「ハイライト」「メモ」「ページ」「位置No.」）は推測。持ち主が日本語のアプリで書き出した実物を受け取ったら、その形に合わせて直す（実物はリポジトリに置かない。reading-002 の T002・T012）。
- 読み方はクラスの名前と並びに頼るので、言葉が違っても同じに読めることを、両方の見本で確かめる。
