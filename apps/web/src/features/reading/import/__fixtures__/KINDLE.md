# Kindle の書き出しの見本（架空）

Kindle のアプリの「ノートブックのエクスポート」の HTML の形を写した、架空の文だけの見本。本物の書き出し（本の文と利用者の名前が入る）は、リポジトリに置かない。

- `kindle-ja.html`：2026-11-28 に持ち主が日本語のアプリで書き出した実物の形を写した（中身は架空）。確かめたこと：
  - ハイライトの見出しの色の印は `span.annotation_<色>`（水色＝aqua など。古い形の `highlight_<色>` ではない）。
  - 見出しは「ハイライト(水色)」「 - 節の名前 > ページ1 ·位置180」の2行。ページと位置の間は「·」で、数字の前に空白がない。
  - `.sectionHeading` は章（「1章　…」。全角の空白）。見出しの「>」の前は節の名前。
  - `.citation` には、引用の形を選ぶと「引用 (MLA): …」が入る。
  - 実物にはメモがなかったので、メモの見出し（「メモ」）は推測のまま。メモのある実物を受け取ったら直す。
- `kindle-en.html`：英語の古い形（`highlight_<色>`・「Highlight(yellow) - Page 9 · Location 55」）。公開されているパーサーの見本から読んだもの（PRD の補足 7章）。
- 読み方はクラスの名前と並びに頼るので、言葉が違っても同じに読めることを、両方の見本で確かめる。
