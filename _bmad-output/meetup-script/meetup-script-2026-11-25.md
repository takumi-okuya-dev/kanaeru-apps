# 台本：IT交流会（2026-11-25）

作成：2026-11-19（仮決め。主催者が寝ている間に作った。読んで、自分の言葉に直して使う）

材料は、主催者が伝えた交流会の流れ（受付 → 開会のあいさつ → 自己紹介 → 席替え → 交流 → アンケート → 閉会・全体で1時間）と、[プロダクトブリーフ](../brief-kanaeru-apps/brief-kanaeru-apps.md)・[PRD](../prd-kanaeru-reception/prd-kanaeru-reception.md)。参加者は20人前後と仮に置いた。

## 1. 時間の割りふり（1時間）

| 時刻（開始からの分） | 場面 | 長さ | 主催者がすること |
|---|---|---|---|
| 開始の15分前〜0分 | 受付 | 15分 | 受付QRで LINE のチェックイン。LINE を使わない人は一覧画面から手でチェックイン |
| 0〜5分 | 開会のあいさつ | 5分 | 交流会のねらい・kanaeru の紹介・今日の流れ |
| 5〜20分 | 自己紹介 | 15分 | 1人40秒の型で回す（20人で約14分） |
| 20〜22分 | 席替え | 2分 | テーブルを入れかえる |
| 22〜50分 | 交流 | 28分 | 各テーブルを回る。困りごとの話を拾う |
| 50〜57分 | アンケート | 7分 | アンケートを開き、アンケートQRを出す |
| 57〜60分 | 閉会 | 3分 | LINEグループ・オープンチャット・次回の案内 |

## 2. 前の日までにすること

- [ ] アプリで交流会を作る（名前・日時・会場・参加費・GoogleフォームのURL・LINEグループの招待リンク）
- [ ] 交流会の LINEグループを作り、招待リンクを交流会に登録する
- [ ] 受付QRとアンケートQRを印刷する（A4 に1つずつ。受付の机と前のスクリーン用）
- [ ] 受付係を頼むなら、招待のリンクを送り、ミニアプリで受けてもらう
- [ ] 自分のスマホで、受付QR → チェックイン → アンケートまで通しで試す（終わったら取り消す）
- [ ] 紙の名簿とペンを予備に用意する（会場の電波が悪いとき用）

## 3. 当日の始まる前（30分前）

- [ ] アプリを一度開いて起こしておく（しばらく使っていないと、最初の1回は数秒かかる）
- [ ] 受付の机に受付QRを置く。PayPay の QR と、現金のおつりも置く
- [ ] 一覧画面を開いておく（チェックインが5秒おきに映る）

## 4. 受付（開始の15分前〜）

受付で声をかけるときの言葉：

> 「こんばんは！ こちらのQRを LINE で読んでいただくと、受付が1分で終わります。お支払いは PayPay か現金で、画面で選んでくださいね。」

- 支払いが済んだら、紙の名札を書いてもらう。
- **LINE を使っていない・使いたくない人**には、無理に勧めない。
  > 「大丈夫ですよ、こちらで受付しますね。」
  → 一覧画面の「手でチェックイン」で名前・申し込みの媒体・知ったきっかけ・支払い方法を入れる。
- 画面が開かない人も、同じく手でチェックインする。会場全体で開かないときは、紙の名簿で受けて、あとで入れる。

## 5. 開会のあいさつ（0〜5分）

> 「みなさん、こんばんは。今日の IT交流会を主催している〇〇です。お集まりいただきありがとうございます。」
>
> 「この交流会は、エンジニアの人も、そうでない人も、仕事の話を気軽にできる場にしたいと思って開いています。」
>
> 「今日は一つ、新しい試みがあります。受付で使っていただいたアプリ、あれは私が作った **kanaeru** というものです。交流会で出た『仕事のここがめんどくさい』という困りごとを集めて、AI活用の勉強会のテーマにしたり、小さなアプリにしたりしていきたいと思っています。最後に1分ほどのアンケートでお聞きするので、今日の会話の中で思いついた困りごとを、頭の片隅に置いておいてください。」
>
> 「今日の流れは、自己紹介 → 席替え → 交流 → アンケート、で1時間です。では、さっそく自己紹介にいきましょう。」

伝えること（言いかえてよい）：

- 交流会のねらい（気軽に仕事の話ができる場）
- kanaeru のひとこと紹介と、困りごとが勉強会やアプリにつながること（約束しすぎない。「つながります」の温度感）
- 最後にアンケートがあること
- 今日の流れと時間

## 6. 自己紹介（5〜20分）

型を見せてから回す。1人40秒。

> 「自己紹介は、①お名前、②お仕事、③最近ハマっていること、の3つでお願いします。1人40秒くらいで。まず私から。」

主催者の見本（40秒）：

> 「〇〇です。仕事はWebとモバイルのアプリの開発をしています。最近ハマっていることは、AIにアプリづくりを手伝ってもらうことで、今日の受付のアプリもその一つです。よろしくお願いします。」

- 時間が押したら「すみません、あと一言でお願いします」と軽く区切る。
- 困りごとはここでは聞かない（入口で考える負荷が高い、とブリーフで決めた）。交流で自然に出てくるのを待つ。

## 7. 席替え（20〜22分）

> 「では席替えをします。いま座っているテーブルとは違うテーブルに移ってください。まだ話していない人の近くがおすすめです。」

- 動きが止まっていたら、主催者がテーブルを指して案内する。

## 8. 交流（22〜50分）

- 各テーブルを回り、会話に入る。困りごとの話が出たら、深掘りして覚えておく（あとでアンケートに書いてもらうきっかけになる）。
  > 「それ、毎回やっているんですか？ どのくらい時間がかかります？」
- 45分ごろに「あと5分ほどでアンケートの時間です」と全体に一声かける。

## 9. アンケート（50〜57分）

1. 一覧画面の準備から**アンケートを開く**。
2. アンケートQRを前に出す（スクリーンか印刷したもの）。

> 「最後に、1分ほどのアンケートをお願いします。受付のときの画面を開き直すか、こちらのQRを読んでください。」
>
> 「お聞きしたいのは、**仕事の困りごと**です。今日話していて『これ、めんどくさいんだよな』と思ったことを、一言で大丈夫です。書いていただいた内容は私だけが読みます。勉強会やアプリにするときに、お名前を出すことはありません。」
>
> 「『実現したら月いくらなら使うか』という質問もありますが、答えるだけで、実際にお金はいただきません。」
>
> 「送ったあとに、いつもの交流会のアンケート（Googleフォーム）へのボタンも出るので、そちらもお願いします。」

- LINE を使っていない人には、口頭で困りごとを聞き、一覧画面から代わりに入れる。
- 7分たったら、アンケートは開いたままで閉会に進む（帰り道でも答えられる）。

## 10. 閉会（57〜60分）

> 「今日はありがとうございました。」
>
> 「アンケートを送った画面に、**今日の参加者の LINEグループ**へのボタンが出ています。今日つながった方と、このあとも話せるように、よければ参加してください。コミュニティ全体の**オープンチャット**も、チェックインの画面から入れます。」
>
> 「集まった困りごとは、私のほうで読んで、AI活用の勉強会のテーマにしたり、小さなアプリにしたりしていきます。『テスターになる』を選んでくださった方には、形になったら私から LINE で直接ご連絡します。」
>
> 「次回は〇月〇日です。また気軽に来てください。お気をつけてお帰りください！」

## 11. 終わったあと

- [ ] 一覧画面の合計（PayPay・現金）と、手元の現金を見比べて清算する
- [ ] 困りごとのタブで、テスターに「はい」の人を「月いくら」の高い順に見る
- [ ] 夜中（0時）を越えて作業するときは、DB の夜間の停止を止めておく（構成の決めごと AD-10）
- [ ] 翌日以降、アンケートを閉じる
