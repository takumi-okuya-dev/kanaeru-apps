# 補足：試合表アプリの組み方（PRD の FR-M8 の中身）

- 作成日：2026-11-22（同じ日に 2章の残す試合を実装に合わせて直した）
- 読む人：試合表を作る Claude Code のセッション（仕様・計画・実装）。
- もとにしたもの：[PRD](./prd-kanaeru-match.md) の 4.2、[.memlog.md](./.memlog.md)。組み方は、持ち主の案に、手元で試した結果から2つの決まりを足して、持ち主が決めた。

## 1. 組み方

レベルの分け方（FR-M6）で分けた組ごとに、1試合ずつ順に決める。ダブルスは試合に入る4人を、シングルスは2人を決める（ペアは決めない。FR-M9）。以下は4人で書く。

1. **周**：組の全員を「この周でまだ出ていない人」の入れ物に入れる。1試合ごとに、入れ物から4人を選んで出し、入れ物が空になったら次の周として全員を入れ直す。これで、全員が1回ずつ出るまで、同じ人は2回出ない（持ち主の案：12人なら 12C4 → 8C4 → 4C4）。
2. **周の残りの中からの選び方**：入れ物の中の人の組み合わせのうち、「これまで同じ試合に入った回数」の2乗の合計がいちばん小さい4人を選ぶ（まだ一緒になっていない人どうしを選ぶ）。同じ点の組み合わせが複数あれば、くじで選ぶ。
3. **周の変わり目**：入れ物に4人いないときは、残りの人を必ず入れ、足りない分を次の周の人から選ぶ（選んだ人は次の周の入れ物から外す）。このとき、直前の試合に出た人はなるべく選ばない。ただし、2の点（顔ぶれを散らす）を先に比べる（持ち主が決めた：顔ぶれを散らすことを、2回続けて出ないことより先にする）。
4. **候補が多いとき**：入れ物が大きい（例：20人）と組み合わせの数が増えるので、くじで選んだ12人の中から2の選び方をする。

くじは種（シード）を試合表に残す。同じ名簿・同じ種なら同じ表になる。「別の組み合わせにする」で種を変える。

## 2. 当日の組み直し（FR-M14）

〈2026-11-22 直した：残す試合を、実装〈match-003 research R2・`plan.ts` の `replanGroup`〉と FR-M14・FR-M15 に合わせた。前は「終わった試合だけを残す」と読めた〉

- 組み直すのは、印を付けた人の組だけ。ほかの組の試合は変えない。
- 最後にチェックした試合までは、そのまま残す（間のチェックのない試合〈飛ばした試合〉も残す。ただし、飛ばした試合に出られない人が入っていれば、その1試合だけを作り直し、試合の場所は変えない）。
- **今の試合**（最後のチェックの次の試合。FR-M15 の「チェックのない最初の試合」。もうコートで始まっているかもしれない）も、入る人がみな出られるなら残す。入る人が来なかった・帰ったなら、今の試合から作り直す。
- 「同じ試合に入った回数」と、今の周の入れ物の中身は、残した試合までの分を引き継ぐ。
- 来なかった人・帰った人は、入れ物とこれからの試合から外す。来た人は、今の周の入れ物に入れる（来るまでの試合は、試合の数を比べるときに数えない）。
- 残した試合の次からを、1の組み方で作り直す。
- 名簿と設定の画面の「組み直す」と、試合表の画面の「別の組み合わせにする」は、すべての組を、最後にチェックした試合の続きから作り直す（今の試合は残さない）。

## 3. 試した結果（手元。1つの組を続けて組んだとき。100回の平均）

| 人数・試合 | 同じ試合に入る回数のいちばん多い組 | 2回続けて出る（延べ） | 試合の数の差 |
|---|---|---|---|
| 5人・8試合 | 6回 | 21 | 1 |
| 7人・8試合 | 4回 | 7 | 1 |
| 12人・12試合 | 約3回 | 0 | 0 |
| 16人・12試合 | 約2回 | 0 | 0 |
| 21人・24試合 | 2回 | 0 | 平均1.2（まれに2） |

- 5〜7人は、休む人が少ないので、2回続けて出る人が必ず出る。
- 8人のように少ない組では、顔ぶれを散らすと、2回続けて出る人が出ることがある（持ち主が決めた優先の順のとおり）。
- 21人でまれに試合の数の差が2になるのは、試合の数が周の途中で終わるため。実装では、周の変わり目の選び方で、差が必ず1以内になるようにする（テストで確かめる）。

## 4. 実装の注意

- **組み方の説明は、組み方の関数の docstring（TSDoc）に書く**（持ち主が決めた）。1〜3の流れ・優先の順・くじの種の扱い・守れない場合を、コードを読む人がこの文書を開かなくても分かるように書く。
- 組み方は画面（端末）で動かす。ネットなしで組み直すため（PRD 4.6）。置き場所は構成の決めごとで決める（PRD 6章）。
- テストは property-based で書く。人数（4〜40人）・試合の数・遅刻と欠席・レベルの分け方を変えた名簿をたくさん作り、毎回次を確かめる。
  - 試合の数の差が1以内（いた間で比べる）
  - 1つの試合に同じ人が2回入らない
  - 来なかった人・帰った人がこれからの試合に入らない
  - 組み直しで、終わった試合が変わらない
  - 同じ名簿・同じ種なら同じ表になる
