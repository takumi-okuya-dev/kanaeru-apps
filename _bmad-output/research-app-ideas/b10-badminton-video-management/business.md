## 0. 結論（先に）

1. **AI で置き換えられる危険は「高」**。「YouTube のリンクに課題の札を付けて保存する」だけなら、スプレッドシートや汎用メモで今すぐ代用できる。事業として残るのは、**練習の記録と動画の振り返りがつながること**と、**課題語を利用者が育てる形**に限られる。
2. **費用は小さい**。AI で札を付けても 1 人あたり月 1 円未満（[2](#2-費用)）。固定費 1,500 円は、有料の人が **4〜6 人**いれば賄える（月 300〜480 円、Web 決済のとき）。ただし、**個人利用が先・収益は二の次**という前提なら、お金より時間の見積もりが大事。
3. **規約で一番注意すること**は、(a) 動画そのもの・字幕・サムネイルを保存しないこと、(b) 有料の壁の向こうで埋め込み再生を止めないこと（API の開発者ポリシー）、(c) API で得た利用者の情報は 30 日までしか持てないこと。いずれも**保存は URL と自分のメモだけ**にすれば避けられる見込みだが、専門家確認が必要。

## 1. 生成 AI に置き換えられる危険

### 1-1. 今の汎用 AI の機能（確認日 2026-11-23）

| できること | 状況 | 出典 |
|---|---|---|
| 会話をまたぐ記憶 | ChatGPT は記憶を自動で更新し、消す・止めることもできる（共通の部分 1-1 と同じ） | [OpenAI ヘルプ（メモリ FAQ）](https://help.openai.com/ja-jp/articles/8590148-memory-in-chatgpt-faq) |
| 公開 YouTube の URL を読む | Gemini API は**公開された YouTube の URL**を入力にできる（プレビュー。無料。非公開・限定公開は不可）。1 回に何本まで渡せるかは資料で食い違う（10 本と 1 本）。要確認 | [Gemini API 動画理解のページ](https://ai.google.dev/gemini-api/docs/video-understanding)（検索要約のみ。本文未確認） |
| 外のアプリとつなぐ | ChatGPT の Apps SDK（共通の部分 1-1 と同じ） | [OpenAI：Introducing apps in ChatGPT](https://openai.com/ja-JP/index/introducing-apps-in-chatgpt/) |

**読み取り**：「この動画の要点を言って」「ヘアピンの動画を探して」は、AI に聞けば済む範囲が広がっている。特に Gemini は URL を直接読めるため、**動画の内容を要約して札を付ける**作業は AI の得意分野になっている（推測）。

### 1-2. 機能ごとの危険度

| 機能 | AI・既存の道具で代用できるか | 危険度 | 理由 |
|---|---|---|---|
| YouTube の URL を課題の札つきで保存する | スプレッドシート・メモアプリ・YouTube の再生リストで代用できる。VideoTag（無料）もある（base の調べもの 3 章） | **高** | 機能が単純で、無料の道具で作れる |
| 札で引く・課題ごとに一覧にする | 同上。検索は既存の道具で足りる | **高** | 単独では差がつきにくい |
| 動画の中の時刻と、自分の言葉のメモを残す | YouTube のタイムスタンプは説明欄に書ける（base の調べもの 4 章）。ただし札やメモとの一覧化は弱い | **中** | 利用者が動画の場所を言葉で振り返れる。ここに隙間がある（推測） |
| 練習記録（いつ・何を練習し・どの課題が出たか）と動画をつなぐ | 練習ノートなどの記録アプリはあるが、動画の添付は確認できず（base の調べもの 3 章） | **中〜低** | kanaeru の他のアプリ（B5 運動管理・B6 試合表）とつなげられるなら、差が出る（推測） |
| 動画の自動要約・自動の札付け | Gemini などで代用できる（上の表）。動画の字幕は API で自由に取れない（[4-2](#4-2-youtube-の-api-と開発者ポリシー) 参照） | **中〜高** | AI に任せる部分は外部の機能で済むため、自前で作る価値は薄い |

**全体の判定：高**。「保存と検索」は AI と無料の道具で代用できる。差を出すなら、**練習の記録とつながり、課題語を利用者が育てる形、AI の代わりに自分で振り返るための見せ方**が必要。

### 1-3. 「AI に任せる」ことが逆に入口になるか

- ChatGPT の Apps SDK や Gemini の連携を使えば、kanaeru の記録を AI から呼べるようになる（共通の部分 1-3 と同じ。提供条件は要確認）。
- ただし YouTube の動画を AI に要約させる場合、その要約結果を kanaeru が保存すると、規約（4-2）の論点が増える。専門家確認。

## 2. 費用

### 2-1. 1 人あたりの費用

| 項目 | 金額 | 出典・メモ |
|---|---|---|
| インフラ（Cloud Run・Cloud SQL 東京） | 1 人あたり月 1 円未満（千人規模まで無料枠の内）。固定費は別 | 共通の部分 2-1（[Cloud Run 料金](https://cloud.google.com/run/pricing)） |
| AI で札を付ける（タイトルと利用者のメモ＋指示を送る場合） | 1 本あたり約 0.02 円（**下の計算**） | 共通の部分 2-2 の価格表 |
| AI で字幕から札を付ける（字幕 5,000 トークンと仮定） | 1 本あたり約 0.09 円 | 同上。字幕の入手は規約で止まる可能性（4-2）。要確認 |
| YouTube API | 無料（クォータの範囲内）。個人利用なら超えにくい | [4-2](#4-2-youtube-の-api-と開発者ポリシー) |

**AI の計算**（[Claude Haiku 5.5](https://platform.claude.com/docs/en/about-claude/pricing)の価格。確認日 2026-11-23）：入力 $0.10／100 万トークン、出力 $0.50／100 万トークン（10 万トークン以下）。為替は 1 ドル＝150 円と仮定【仮定。140〜160 円で動く】。

- タイトルとメモ＋指示で入力 800 トークン、出力 100 トークンの場合：$0.00008 + $0.00005 ≒ $0.00013 ≒ **約 0.02 円／本**。
- 字幕込みで入力 5,800 トークン、出力 100 トークンの場合：$0.00058 + $0.00005 ≒ **約 0.09 円／本**。
- 送るのは利用者本人の動画に限る。一括処理（バッチ）なら半額（同じ出典）。
- 推論型のモデルは、考えた分も出力として請求される。出力が 2〜5 倍になると見ておく【仮定】。

**1 人あたり月の目安**：動画を月 30 本保存する人の AI 費用は、タイトルだけなら 1 円未満、字幕込みでも約 3 円。**1,000 本まで上げても 100 円に届かない**（推測）。AI は値付けにほぼ効かないが、字幕を全部送る使い方を許すと費用が膨らむので、上限を決める。

### 2-2. 損益分岐（固定費 1,500 円）

**前提**
- 固定費：月 1,500 円（依頼どおりの基準）。kanaeru の共通の土台に載せる場合、この app だけの増分はほぼゼロ（無料枠の内）。単独で置く場合は Cloud SQL を 24 時間動かす費用（約 $10／月、集計サイトの値。要確認）が増える（共通の部分 2-1）。

### 2-3. 解約率（仮定）と、1 人が残すお金

**解約率は仮定**【仮定。検証していない】。根拠の目安：一般消費者向けのサブスクは月 6.77%（[Recurly churn benchmarks](https://recurly.com/research/churn-rate-benchmarks/)）。小さい個人用の道具は、これより高くなる可能性がある（推測）。

| 解約率（仮定） | 平均の残り期間 | 1 人が残すお金（LTV） |

| 5% | 20 か月 | 約 9,100 円 |

**読み取り**：有料の人を 10 人保つには、解約率 10% なら毎月 1 人の補充が要る（10 × 10%）。個人用の道具では、この補充の方が大きな仕事になる（推測）。

### 3-2. 値付けの案（仮決め）

- **無料**：動画の保存は一定の本数まで（例：30 本）。札付け・検索・1 本ごとのメモは無料。
- **有料**：月 300〜480 円、年 3,000〜4,800 円（共通の部分 4-2 の「月 480 円」と揃える）。本数の上限と、書き出しの機能を有料に入れるかは専門家確認後に決める。
- 理由：Instapaper の $5.99 は記事の読み上げと大量の保存が前提。この app は保存数が少ないので、高い値は付けにくい（推測）。

### 3-3. スイート（まとめ）か、個別の販売か

- **スイートに入れる（推奨）**：スイート「kanaeru プラス」（月 480 円、共通の部分 4-2）の中の一機能にする。1 人で使う前提なら、個別に売ると、月 300〜480 円の壁に「もう一つの有料」が加わり、解約の理由になる（推測）。
- **個別に売る**：B10 だけで有料にするなら、月 300 円前後・年 3,000 円前後。ただし、有料の人を 4〜6 人（2-2）集める手間と、解約の補充（2-3）を考えると、副収入としては割に合いにくい。
- 個人利用が先なので、**課金の仕組みは後回しにしてよい**（依頼どおり）。

## 4. 法律・規約（専門家確認が前提。結論ではない）

### 4-1. YouTube の利用規約（確認日 2026-11-23。発効 2023-06-01）

- 「許可と制限事項」：コンテンツの**アクセス・複製・ダウンロード・配信・改変**などは、YouTube が明示的に認めた場合か、事前の書面許可がない限り禁止（[YouTube 利用規約](https://www.youtube.com/t/terms)）。
- 「自動化された手段（ボット・スクレイパ）でのアクセス」も禁止（同じ出典。robots.txt に従う公開の検索エンジンの例外）。
- 視聴は「個人的で、非営利目的」に限られる、という記載がある（同じ出典）。**有料の app で動画を見せる場合、この「非営利」の範囲をどう読むかは専門家確認**。
- 論点：利用者の動画の「保存」（URL の保存は、コンテンツの複製に当たるか）。専門家確認。

### 4-2. YouTube の API と開発者ポリシー

API を使うと（例：利用者が自分の再生リストを読む、動画の情報を取る）、開発者ポリシーが適用される（[YouTube API Services 開発者ポリシー](https://developers.google.com/youtube/terms/developer-policies)。確認日 2026-11-23。更新日の表示なし）。

| 条項 | 内容（要約） | この app への影響 |
|---|---|---|
| III.E.1.a：動画の保存 | YouTube の動画コンテンツを、**書面の承認なしにダウンロード・取り込み・バックアップ・キャッシュ・保存してはいけない** | 動画本体・音声・字幕・画面の録画は保存しない。**URL と利用者のメモだけ** |
| III.E.4：保存期間（利用者の同意で得た API データ） | 「利用者が同意して得た API データ」は**30 日を超えて保存できない**。利用者は削除を求められ、7 日以内に消す必要がある | 利用者の再生リストを API で読んで保存する機能を作るなら、30 日ごとに取り直す設計が要る |
| III.I：埋め込みプレーヤー | プレーヤーを改変・妨害・ブロックしてはいけない。YouTube の表示（帰属・リンク）を消さない。**埋め込みを見るのに料金を取ったり、「再生ボタン以外の行動」を要求したりしてはいけない**（[要件の説明](https://developers.google.com/youtube/iframe_api_reference)、検索要約） | 有料の壁の向こうで埋め込み再生を止めない。「YouTube 由来」の表示を残す。Referer ヘッダーを消さない（検索要約。本文未確認） |
| III.E.6：スクレイピング | YouTube のアプリや Google のアプリを、直接・間接にスクレイピングしてはいけない | 動画ページの解析で札や字幕を取らない |

**クォータ（API の使える量）**：1 日の既定の上限は 10,000 単位（変わることがある）。一覧の読み取りは 1 単位（videos.list・playlistItems.list）。search.list は既定で 1 日 100 回まで。再生リストの作成は 50 単位（[クォータの概要](https://developers.google.com/youtube/v3/getting-started)・[単位の表](https://developers.google.com/youtube/v3/determine_quota_cost)。確認日 2026-11-23）。個人利用なら超えにくい。公開して多くの人が使うなら、上限の引き上げ申請が必要。

### 4-3. 著作権（リンク・埋め込み・保存・文章）

- **リンク（URL を保存する）**：リンクそのものが公衆送信権の侵害の幇助に当たるかは、審議会の資料で議論が紹介されている。裁判例も一様でない（[文化審議会 著作権分科会 法制・基本問題小委員会](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/hoki/h29_06/)。検索要約のみ。本文未確認。要確認）。**一般の YouTube 動画の URL を保存する行為が、どこまで問題になるかは専門家確認**。
- **埋め込み（公式の埋め込みプレーヤー）**：YouTube が提供する埋め込みを、規約どおりに使う形（4-2）。
- **保存（動画・字幕・サムネイルの複製）**：複製・ダウンロードは規約で禁止（4-1・4-2）。加えて著作権法の論点もある。個人が私的に複製する例外（第30条）はあるが、規約が別に禁止している。**保存しない設計にする**。

### 4-4. 個人情報保護法（小さく始めるが、3 つは気をつける）

- 個人情報のデータベースを事業に使う人は、件数にかかわらず対象になる（[個人情報保護法（e-Gov）](https://laws.e-gov.go.jp/law/415AC0000000057)。共通の部分 5-5）。
