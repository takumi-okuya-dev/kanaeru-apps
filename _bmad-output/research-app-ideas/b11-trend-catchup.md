作成：2026-11-23（`/app-idea-research` で作った。主張には出典を付け、確かめきれないものは「要確認」。法律の判断はしていない）

材料：[市場と似たアプリ](./b11-trend-catchup/market.md)・[レビューと勝てる所](./b11-trend-catchup/reviews.md)・[事業性](./b11-trend-catchup/business.md)・[深掘り：興味の外に出会う](./b11-trend-catchup/serendipity.md)（共通の土台は [事業性の共通の部分](./business-viability.md) にリンクのみ）

## 1. ひとことで

- **判断**：あとで作る
- **売り方**：スイートに含める（受付アプリ〈B2〉と交流会の無料の付録）
- **理由**：
  - 「今週の流行りを教えて」は ChatGPT の無料のタスク・LINE NEWS・Yahoo! で足り、生成AIに置きかえられる危うさは高い。単独で課金する余地は小さい。
  - 空いているのは「交流会の前に、参加者全員が同じ雑談ネタ3つを持つ」非パーソナライズの形。費用は月数円〜数百円の固定で小さい。
  - 痛みは人に会う前の「ときどき」で、需要の数字がない。重い論点は記事の中身の要約。まず 2026-11-25 の交流会で手作りのネタを配って確かめてから作る。

## 2. 困りごと（主催者の言葉のまま）

- 私は家にテレビがないので、最近の流行りについて行くことができていません。
- 最近のアプリはパーソナライズが進みすぎて自身の興味のない分野の情報が入ってきにくい状況にあります。(自身の他分野ほど、新しい発見があると最近思いました。)

**あとから主催者が出した案（主催者の考えで、調べた事実ではない）**

- 作りの型は3つありうる：**パーソナライズ**・**非パーソナライズ**・**特定の情報源から要約**。
- 「興味の外に出会う」は、言いかえると「利用者が興味のない中身」を見せることなので、魅力を伝えるのが難しい。

## 3. 市場と似たアプリ

テレビを持つ世帯は 90.1%（総務省、2025年8月末。確かめ済み）だが、29歳以下の一人暮らしの男性では 58.1%（内閣府、2026年3月末。148世帯の抽出で誤差が大きい）。平日に15分以上リアルタイムでテレビを見た人は 79%（2020年）→ 71%（2025年）、20代は 33%（NHK、報道で確認。公式資料は**要確認**）。15〜34歳が流行を知る入口は TikTok・YouTube・Instagram・X・テレビがほぼ横並び（466人の1調査で**要確認**）。「テレビのない人が人と会う前に短く追いつく」専用のサービスは見つからなかった（[market.md 1・4章](./b11-trend-catchup/market.md)）。

## 4. レビューから見えた勝てる所

| よく出る不満 | 出典 | 主催者の困りごとと重なるか | 小さなアプリで持てる違い |
|---|---|---|---|
| 古いニュースが上に残る・X の方が早い | スマートニュースの★1〜2（[app-ranking.net](https://www.app-ranking.net/id/579581125)、2026-11-18・11-13・11-08） | 高い | 速さではなく選び方で勝つ。週1回・少ない数に決めて「今週みんなが話していたこと」だけ出す |
| 興味のない記事が大量で、何が皆の話題か分からない | 同（2026-10-27・09-30） | 高い | 記事の一覧ではなく「話題の名前＋なぜ話題か＋会話の一言」。数を固定する |
| ネタバレがタイトルに出る | 同（2026-11-19・10-03）、グノシー（2018-06-11） | 高い | 結末は書かない・畳んで隠すのを標準にする |
| 話題を知るために長く見るのはタイパが悪い | TVer の★1（[app-ranking.net](https://www.app-ranking.net/id/830340223)、2026-08-10） | 高い | 人に会う前の3分で読み切れる量。番組は公式へのリンクで案内するだけ |
| 見逃し配信が1週間で終わる | TVer の★2（2026-11-05） | 高い | 「いま見られる」へのリンクだけ添える |
| コメント欄が荒れていて不快・偏った政治記事 | Yahoo!ニュース（[app-ranking.net](https://www.app-ranking.net/id/407906756)、2025-12-21）、スマートニュース（2020-09-12） | 中 | コメント欄を持たない。政治の左右を軸にしない |
| 広告が多い・誤タップ | 4つのアプリすべて（2026-11 の複数） | 中 | 広告を載せない |

テレビのない人の声（X・知恵袋・ブログ）では、困るのは**人と話す場面**（美容院・職場・家族）で、生活そのものは困らないという声が多い。「聞けば会話に入れる」という回答もあり、痛みは毎日ではない（[reviews.md 2章](./b11-trend-catchup/reviews.md)）。

勝ちにくいもの：中身の量と速さ（大手は数十社の記事を許諾つきで受け取り、AI で要約している）。利用者の規模（LINE は国内月間 1億人）。テレビ番組の中身（画像・セリフは使えない）。さらに、2026年の流行語大賞の候補ではテレビ発の語がゼロと報じられ、流行の出どころがテレビから離れている（[reviews.md 4章](./b11-trend-catchup/reviews.md)）。「テレビの代わり」より「みんなが話していることの代わり」と捉え直すほうが合う（推測）。

## 5. 事業性

| 観点 | 中身 |
|---|---|
| 生成AIに置きかえられないか | 危うさ：**高**。ChatGPT は無料プランでも毎週のまとめを通知まで含めて自動で作れる（3件・1日1回まで。公式ヘルプで確かめ済み）。Gemini・Claude・Perplexity にも決まった時刻に動く機能がある。AI 以外でも LINE NEWS・Yahoo!・Google トレンドが無料。AI に聞けば済む以上に要るのは、**その交流会に合わせて主催者が選ぶこと**（危うさ 中）と、**同じネタをその会の全員で持つこと**（危うさ 低〜中）だけ（[business.md 2章](./b11-trend-catchup/business.md)）。 |
| お金の計算 | 1人あたりの月の費用：AI 約1円（質問・好みに合わせる分）＋インフラ約1円。全員に同じまとめを作る AI の費用は月 約4円（材料を自前で集める）〜約210円（AI の Web 検索を使う）の固定（Claude Haiku 5.5 の公式の値・1ドル＝150円は仮定。料金表は1ページのみで**要確認**）。重いのは X の API（読んだ投稿1件 $0.005。週1,000件で月 約3,200円）と LINE の Push（無料プランは月200通。週1回なら46人まで）。損益分岐：土台 1,500円なら、月 480円で Web 決済 4人（仮定。主催者が毎週ネタを書く時間は入っていない）。ただし、すすめは無料の付録なので、売り上げではなく人を呼ぶ道具として見る。 |
| 値付けと課金の手段 | 比べる相手は無料（LINE NEWS・Yahoo!・ChatGPT の無料のタスク）。個人の有料の配信は月300〜500円（note メンバーシップは 500円以上をすすめる。**要確認**）。取材をしない「まとめ」は、無料と ChatGPT の間に値段をつけにくい。**受付アプリ（B2）の無料の付録**にし、払ってもらうならスイート（月 480円案）のおまけに留める。単独の有料はアンケートで払う額を聞いてから。課金するなら Web（Stripe 約4.3%）。自前のスマホアプリは作らない（[business.md 4章](./b11-trend-catchup/business.md)）。 |
| 法律・規約・商標 | **一番重い論点は記事の本文の要約**。日本新聞協会は、記事を材料にした生成AIの回答は著作権侵害の可能性が高いとし、許諾と対価を原則としている。大手の AI まとめは許諾を得た記事だけを使っている。見出しも、大量に並べて配ると不法行為とされた判決がある（YOL 事件。判決の要旨は本文を読めず**要確認**）。テレビの画像・セリフ・歌詞は使わない。X の API は再配布・派生物・AI の学習を禁じる条項がある。YouTube は公式の API だけ。参加者が話したことを材料にするなら個人情報の論点が重い。**どれも専門家の確認が要る**（[business.md 5章](./b11-trend-catchup/business.md)）。 |

## 6. kanaeru との相性

- 玄関（受付アプリ・交流会・LINE）とのつながり：**強い**。交流会の前に受付アプリ（LINE ミニアプリ）の画面で「今日の雑談ネタ 3つ」を見せれば、AI にない「その会の全員で同じネタ」が作れる。人を呼ぶ道具にもなる（推測）。
- 1人で作るときの手間の目安：画面は小さい（3件を出すだけ）。いちばんの手間は**毎週のネタを自分の言葉で書いて確かめる時間**で、週30分かかればそれが最大の費用になる（[business.md 3-5](./b11-trend-catchup/business.md)、仮定）。X の API・記事の取り込み・1人ずつの作り分けは最初の版に入れない。

## 7. 危うさ

- **いちばん大きいのは、使われる理由が弱いこと**。痛みは人に会う前の「ときどき」で、「困らない」「聞けば会話に入れる」という声も多い。無料の大手と AI のタスクがすぐ近くにある。
- 記事の本文を AI で要約すると著作権の論点が重い。見出しを大量に並べるのも危うい（専門家の確認が要る）。
- 毎週ネタを書き続ける手間。止まれば価値がなくなる。
- 流行の出どころがテレビから離れており、「テレビの話題」に絞ると外れるおそれ。
- 参加者が実際に話したことを材料にするなら、個人情報と同意の設計が重い（最初の版ではしない）。

## 8. 次の一歩

- **2026-11-25 の交流会で安く試す**：主催者が「今日の雑談ネタ 3つ」（自分の言葉で、なぜ話題か・会話の一言・公式へのリンク。ネタバレなし・政治の左右なし）を手で作り、受付で配る（受付アプリの画面、できなければ紙）。受付のアンケートに「雑談ネタを使ったか」を1問足し、できれば「次回も欲しいか」も聞く。名前は取らず、数だけ数える。
- 結果で決める【仮決め】：使った人・欲しい人が多ければ、受付アプリの無料の付録として作る候補にする（早く作るへ上げる）。少なければ **作らない** にする。
- 何回か続けて手で作ってみて、毎週のネタ作りに何分かかるかを測る。
- 作る前に、見出しとリンクの使い方・47条の5・引用の範囲を専門家に確かめる。記事の本文の取り込みはしない。
- パーソナライズ・特定の情報源から要約の2つの型は、上の試しがうまくいってから考える。
