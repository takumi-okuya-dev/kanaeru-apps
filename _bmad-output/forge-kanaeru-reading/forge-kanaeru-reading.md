# 練った構想：B3 読書記録

2026-11-27。`/bmad-forge-idea` で練った（経緯は [.memlog.md](./.memlog.md)）。PRD（`/bmad-prd`）の入力。

> **このあと PRD で変えた**（2026-11-27。[PRD](../prd-kanaeru-reading/prd-kanaeru-reading.md) 11章）：中心の行動「読み終えるたびに LINE に一言」をやめ、すでに引いているマーカーとコメントを取りこむ形にした。主な用事を c（人に話せる・書ける）と b に広げた。LINE はログインと、利用者自身の LINE から送ることだけにした（届いた文を振り分ける仕組み・リッチメニューのモードは要らない）。下の決めごとと食い違うところは、PRD が正。

## 決めたこと

- **主な仕事**：読んだ本で、仕事での**行動が変わる**こと（b）。覚えている（a）・説明できる（c）は理想として残し、足す順は b → c → a。
- **困りごと**は「ページが見つからない」ではなく「読んでも実践して身につかない」と「読むのが遅く、前の内容や全体像を見落とす」。
- **読む場所**は Kindle と GoodNotes 5（PDF）のまま。アプリは読む場所をまとめさせず、本文や線も取りこまない。
- **中心の行動**：読み終えるたびに、LINE に**要点の一言**（10秒）を送る。「やる：…」は任意。
- **本**は1冊1回だけ登録する（書誌の API から候補。なければ手で書いた名前）。一言は直前の本に入れ、返事に「違う本」のボタンを付ける。時間がたっていたら読んでいる本をボタンで聞く。読み終わった・やめたもボタン1つ。主催者は2〜5冊を並行して、部分的に読む。
- **章**は一言の要の欄。「3章」「p.120」を拾い、なければ返事のボタン（前と同じ章・次の章・飛ばす）で聞く。
- **全体像**＝自分の一言を**章の順**に並べたもの（読んだ順ではない）。目次を貼って読んでいない章も見せるのは、後から足すオプション。
- **「やってみた？」**：「やる」への返事に「Google カレンダーに入れる」のリンク（2週間後）を付ける。次に一言が届いたときの返事でも聞く。結果（やった・まだ）を残す。
- **無課金**：LINE 公式アカウントは無料のプラン（こちらから送るのは月200通まで、買い足せない）。中心の流れは返事（無料）だけで回し、こちらから送らない。AI の利用料は PaletKit が持たない（AD-20・原則 V）ので、最初の版は AI を呼ばない。
- **LINE**：PaletKit の公式アカウントを、個人で使うアプリ（読書・人物メモなど）で分け合う。届いた文の宛て先は、**リッチメニューのモード切り替え**で見分ける（最後のモードを覚え、時間がたっていたらクイックリプライで聞く）。受けて振り分ける仕組みは**共通の PR で先に作り**、アプリは1行に1つの一覧に受け手を登録する。人物メモ（B7）のセッションと同じ決まりにする。
- **夜0時〜8時**（DB が止まる。AD-10）は受けない。返事で、DB を見ずに「止まっています。朝にもう一度」と返す。
- **書き出し**：本ごとに Markdown（書名・著者・ISBN・章の順の一言・やること・結果）。ブログの材料にする。利用者が設定した**自分のアソシエイトの ID 付きのリンク**を入れられる。下書きは AI の段階1（頼む文をコピー）。
- **最初の版は交流会とつなげない**。主催者が自分で2〜4週間使う。一番見るのは「**行動に変わったか**」（「やる」を書き、カレンダーで知らされて実際にやった回があるか）。よかったら、受付のチェックインのあとの案内と、交流会で紹介された本を読みたい本リストに入れる機能を検討する。

## 捨てたこと・後に回したこと

- 撮って索引（紙のページの OCR）：主に電子書籍で読むので合わない。
- 線の取りこみ（Kindle・GoodNotes）：外へ出す公式の道が細い。a（覚えている）の段階で考え直す。
- 本そのものの要約・AI が作る目次：AI と大手に置きかえられ、著作権の面でも危うい。
- LINE からこちらへ送る呼び戻し（週1回の「どこまで読んだ？」など）：無料の枠を交流会の知らせと取り合う。
- 読みたい本リスト・PaletKit が稼ぐアフィリエイト：b が回ってから。**PaletKit が稼ぐアフィリエイトは後で必ず作る**（2026-11-27 主催者が決めた。読みたい本リストなど、まだ買っていない本に「買う」のリンク）。作る前に、景品表示法のステマ規制と Amazon アソシエイトの規約を確かめる。

## まだ決めていないこと

- 予約（交流会の知らせ）で設定している公式アカウントは、PaletKit の公式アカウントと同じか。同じなら、文を受ける仕組みを予約の受け口とつなげる必要があり、200通の枠も交流会と分け合う。
- 書誌の API（openBD・Google Books・国立国会図書館）の利用条件。
- 2026年の LINE の料金を、公式の料金ページで確かめる。
