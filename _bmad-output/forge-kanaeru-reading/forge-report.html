B3 読書記録：練った構想の報告

2026-11-27 ／ 結果：固まった（HARDENED）。PRD（/bmad-prd）に渡せる形。

ひとことで：読み終えるたびに LINE へ要点の一言。章の順に並べて全体像を、「やる」は Google カレンダーで「やってみた？」に。無課金で回す。

決めたこと

主な仕事読んだ本で、仕事での行動が変わること（b）。覚えている（a）・説明できる（c）は後に足す（順は b → c → a）
困りごと「実践して身につかない」と「読むのが遅く、前の内容や全体像を見落とす」。「ページが見つからない」は主役ではなかった
中心の行動読み終えるたびに、LINE に要点の一言（10秒）。「やる：…」は任意
本と章本は1冊1回の登録。一言は直前の本に入れ、「違う本」のボタンで直す。章は要の欄（「3章」「p.120」を拾い、なければボタンで聞く）
全体像自分の一言を章の順に並べる。目次の上に読んでいない章も見せるのは後のオプション
やってみた？「やる」への返事に Google カレンダーのリンク（2週間後）。次の一言への返事でも聞く
無課金LINE は返事（無料）だけで回し、こちらから送らない。AI の利用料は持たない（最初の版は AI を呼ばない）
LINEPaletKit の公式アカウントを分け合う。リッチメニューのモード切り替えで宛て先を見分ける（共通の PR を先に。人物メモとそろえる）
夜0〜8時受けない（DB が止まる）。「朝にもう一度」と返す
書き出し本ごとに Markdown（ブログの材料）。利用者が設定した自分のアソシエイトの ID 付きのリンクを入れられる
最初の版交流会とつなげず、主催者が2〜4週間使う。一番見るのは行動に変わったか

捨てたこと・後に回したこと

  • 捨てた撮って索引（紙のページの OCR）：主に Kindle と GoodNotes（PDF）で読むので合わない
  • 捨てた本そのものの要約・AI が作る目次：AI と大手に置きかえられ、著作権の面でも危うい
  • 捨てたLINE からの呼び戻しの push：無料の200通を交流会の知らせと取り合う
  • 後に回した線の取りこみ（Kindle・GoodNotes）：a（覚えている）の段階で考え直す
  • 後に回した読みたい本リスト・PaletKit が稼ぐアフィリエイト：b が回ってから。アフィリエイトは後で必ず作る（主催者が決めた）。作る前に規約と景品表示法を確かめる

叩かれても残った弱い所

  • 一言をやめた人を、誰も呼び戻さない（無課金と引きかえ）
  • 直前の本に入れる決め方は、2〜5冊を並行して読むと外れることがある（「違う本」で1タップ）
  • 予約で設定している公式アカウントが PaletKit のものと同じなら、文を受ける仕組みの形と200通の枠の分け方が変わる（未決）
  • 書誌の API の利用条件と、2026年の LINE の料金は要確認
