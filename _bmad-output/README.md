# 構想の出力先

BMAD-METHODのスキル（`/bmad-brainstorming`・`/bmad-product-brief`・`/bmad-prd`など）が、構想・プロダクトブリーフ・PRD・調べものをここに書き出す（`_bmad/config.toml`の`output_folder`）。

- どのスキルを使うかは[AIスキルの使い方](../docs/ai-skills.md) 3。
- PRDが固まったら、`/speckit-constitution`で原則を[Constitution](../.specify/memory/constitution.md)に移し、実装はspec-kitで進める。
